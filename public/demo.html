SoloSerial Demos

This page shows how to use the SoloSerial library, which can be loaded using a <script> block; either directly from GitHub Pages, or from a local copy.

⚠ Web Serial is not available in this browser. Use Chrome, Edge, or Opera on desktop and serve over HTTPS or localhost.

Widget

SoloSerial.createWidget(parent, options) renders a self-contained connect/disconnect button with device info. It auto-connects when a previously paired device is found.

Programmatic connect

SoloSerial.connect(options) connects, probes the device, and returns { device, info, state }. Must be called from a user-gesture handler.

Minimal integration snippet

Drop this into any webpage to add a solo-serial connect widget:

<!-- Load the library (major.minor-version URL stays stable within v0.1.x) -->
<script src="https://solo-fsw.github.io/solo-serial-web/lib/v0.1/solo-serial.js"></script>

<div id="solo-panel"></div>

<script>
  // Create the widget — no framework required.
  const { device } = SoloSerial.createWidget(
    document.getElementById('solo-panel'),
    {
      // Optional: only show devices matching this vendor ID.
      // filters: [{ usbVendorId: 0x2341 }],

      onConnect(device, info, state) {
        console.log('Connected to', info.name, '— firmware', info.firmware_version);
        // Send a command:  device.sendCommand('myCommand', 'arg1');
      },
      onDisconnect() {
        console.log('Device disconnected.');
      },
    }
  );
</script>
